# alyze-cjk

CJK (Chinese, Japanese, Korean) text analysis for [`alyze`](../), enabled through its `cjk`
feature and re-exported as `alyze::cjk`. Kept as a separate crate so the dictionaries (`data/`,
about 4.7 MB) don't inflate `alyze` for users who don't need them.

Currently provides `smartcn`: a port of Apache Lucene's `smartcn` analyzer, the Hidden Markov
Model word segmenter for Simplified Chinese behind Elasticsearch's `smartcn` analyzer and
`smartcn_tokenizer`. The tokenizer stage reproduces Lucene's output exactly (checked against
golden files generated by Lucene itself, see `testdata/smartcn/README.md`); the analyzer stage
stems English with Porter2 where Lucene uses Porter.
